## Behavior delivered

One CodeMirror 6 `EditorView` is created on mount, updated with compartments/transactions, and destroyed on unmount. Local typing/paste emit the complete next source via `onChange`. Parent-driven replacement is annotated internally, does not echo `onChange`, and accepted feedback does not reset cursor/scroll. If the parent retains the previous source, the document is reconciled after `tick()` without a second source callback.

`editable=false` sets both `EditorView.editable` and `EditorState.readOnly`, plus change/transaction filters and paste/cut/drop handlers. Selection, scrolling, and copying remain usable. Switching back to edit permits changes. External replacement still applies in view mode.

Selection uses CodeMirror UTF-16 document offsets (each internal line break is one position, even when `sliceDoc()` serializes CRLF). Finite offsets are truncated and clamped; non-finite selections are ignored. `selection=null` means no override. Selection callbacks are not emitted for prop-driven transactions.

Uniform LF and CRLF round-trip via `EditorState.lineSeparator` and `sliceDoc()` (not `doc.toString()`). Documents without line breaks default to LF. Mixed LF/CRLF or standalone CR destroys the EditorView and shows the original raw text with a read-only explanation. No CodeMirror history extension is installed. Mod-Z / Mod-Shift-Z / Ctrl-Y emit `onHistoryRequest` only in edit mode and do not change text. The demo labels those as fixture events and has no undo stack.

## Limitations / Astra decisions

1. **Mixed LF/CRLF and standalone CR are unsupported in this widget.** The original bytes are shown read-only. Full editor integration still needs an Astra decision for mixed-separator documents.
2. **Selection offsets are editor positions, not compiler source spans.** CRLF `sliceDoc()` output is longer than the internal document used for `anchor`/`head`.
3. **History is a request only.** The component never installs CodeMirror history or a demo stack. Shared semantic Undo/Redo remains reserved.
4. **`standardKeymap` is included for ordinary editing keys** (arrows, delete, enter) without `history()` / `historyKeymap`.
5. **No Astra acceptance is claimed.**
