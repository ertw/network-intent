Serialization is UTF-8, indent 2, final newline, with no dates or host paths.

Each release must also contain capabilities plus `uci-network`, `uci-changes`, `netifd-interfaces`, and `netifd-devices` JSON. JSON is parsed strictly (duplicate object keys and non-finite numeric constants are rejected). Symlinks, unexpected nested directories, and unknown release directories are rejected rather than followed.
