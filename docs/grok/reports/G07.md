## Behavior delivered

Read-only renderer of already-projected nodes/edges. IDs, labels, subtitles, and layer tags are preserved as supplied display data. Layout clones and sorts a copy by ID, then runs bundled ELK (`elkjs/lib/elk.bundled.js`, no remote worker URL) with layered / RIGHT / inter-layer 80 / node spacing 40. Canvas nodes are fixed 200×80. Explicit `in`/`out` handles so parallel edges and cycles render. Svelte Flow CSS is imported only inside this feature.

While layout is in flight the previous canvas is removed and a loading message is shown. Only the latest generation may present a graph or an error. Unmount disposes outstanding requests. Duplicate node/edge IDs, overlapping node/edge IDs, and dangling endpoints show a visible diagnostic and do not silently drop data. Empty input shows **No graph to display**.

`selectedId` is authoritative. Node/edge clicks and the accessible list call `onSelect(id)`; pane click calls `onSelect(null)`. Parent-ignored selection does not change the highlight. Nodes are not draggable or connectable; `deleteKey={null}` plus `onbeforedelete` / `isValidConnection` / `onbeforeconnect` block mutation. Full labels remain in the keyboard-accessible lists even when the canvas box truncates them.

Race coverage is in `layout-session.test.ts` with an injectable layout function (A then B, B then A; current reject; dispose before resolve). Browser tests run actual ELK and Svelte Flow.
