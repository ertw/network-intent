## Behavior delivered

Read-only `SnapshotPanel` using frozen `SnapshotPanelProps` only. Title and snapshot ID render as supplied; `snapshotId === null` shows **No snapshot**. Datastore labels are distinct: **Committed configuration**, **Session staging**, **Configuration in use**, **Operational state**. None is shortened to “Applied”.

Provenance shows source, collected/received timestamps (null → **Unknown**, otherwise the exact ISO string), freshness, completeness, missing items, and unavailability reason. Timestamps are not compared to the clock; freshness is not calculated. Empty `missing` uses the UI placeholder “No missing items listed”. Null `reason` uses the UI placeholder “None supplied”.

Groups and fields render in supplied order. Scalars stay strings (`0`, `false`, `007`, empty string, doubled spaces). Ordered lists keep duplicates and empty-string entries; a zero-length list shows **Empty list**. Redacted fields show the text **Redacted** only: no value node, no `title`/tooltip, no copy/reveal control. Unknown fields show the supplied reason, tagged **Unknown**, and do not reuse the empty-scalar, empty-list, or redacted markup.

No groups: **No operational details** for `operational`, **No configuration details** for the three configuration datastores. Partial/unavailable completeness still shows a warning that absence of groups is not proof of no configuration.

Text uses Svelte interpolation (no `{@html}`). Long values use a scrollable `pre-wrap` area (`overflow: auto`, no ellipsis). Coordinator verification found Chromium does not scroll a focused overflow box on End/PageDown by default; `SnapshotPanel` now handles those keys on the value box and uses `min-height: 0` so `max-height` actually clips. The production component has no edit, save, apply, or retry controls (`<pre>` is used so Playwright does not see a textbox). Demo-only selector, reset, and counters stay outside `SnapshotPanel`. Synthetic fixture labels all start with `Synthetic:`.

## Limitations / Astra decisions

1. **Null optional provenance strings.** The contract uses `null` for timestamps and `reason`. Timestamps follow the packet (**Unknown**). `reason: null` has no specified sentence; the UI shows **None supplied** as chrome, not a collector reason. Empty `missing` shows **No missing items listed**. Decision: keep as display placeholders, or omit those rows.
2. **Completeness warning copy.** There is no separate warning string on `Provenance`. Partial/unavailable banners are derived from `completeness` plus the packet sentence that absence of groups is not proof of no configuration. That is display of the supplied enum, not a new completeness decision.
3. **No panel callbacks.** `SnapshotPanelProps` has no `onChange` / retry / apply. Demo counters track only fixture selection/reset. The component cannot emit mutations.
4. **Empty-string snapshot ID.** `null` renders **No snapshot**. An empty string would render as an empty ID value. No synthetic case uses `snapshotId: ''`.
5. **Redacted has no hidden payload.** The field kind carries no value to leak; the component does not invent a masked preview or redactor identity.
6. **Keyboard scroll is explicit, not native overflow-box behavior.** Chromium left `scrollTop` at 0 on End/PageDown for a focused overflow `<div>`/`<pre>`. Coordinator added `applyScrollKey` rather than changing the spec or using a `<textarea>` (the spec forbids textboxes in the production panel).
7. **Svelte a11y ignores.** Focusable read-only `<pre>` uses `svelte-ignore` for `a11y_no_noninteractive_tabindex` and `a11y_no_noninteractive_element_interactions` because the packet requires keyboard scrolling without mutation controls.
