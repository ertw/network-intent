## Behavior delivered

Entries keep supplied order. Selection calls `onSelect(id)` and follows `selectedId`. Parent-ignored selection does not change the highlight. Null or absent `selectedId` shows no detail; an unknown id invents none.

Selected detail shows Before and After field groups. Empty Before/After arrays display **No fields supplied** (not Unknown). Empty scalars show the **Empty value** label with empty value text. Empty lists show **Empty list**. Ordered lists keep duplicate and empty entries as separate items. Redacted fields show **Redacted** with no raw secret. Unknown fields show **Unknown** plus the supplied reason. Null explanation displays **No explanation supplied** and is not treated as a safety proof. Whitespace is preserved with `pre-wrap`. HTML-like strings render as text.

There are no approve/accept/apply/adopt/merge/undo controls. Long values are scrollable locally (copied scroll helper in this feature; modified navigation keys are not consumed).
